A language for interactive math figures

Math figures that readers can drag, slide and play.

You write what a figure is. The compiler checks it, and any web page can draw it.

Get started See the examples
unit-circle.mtp, 15 lines
; cos θ and sin θ for a point on the unit circle: drag the point or turn the slider
(import house ink soft red green number)
(import marks)
(real theta 40 (wrap 0 360))
(scene s
  (marks.axes_ (left -1.3) (right 1.3) (bottom -1.3) (top 1.3) (stroke soft))
  (circle rim (r 1) (fill none) (stroke ink) (stroke-width 1.5))
  (line cos (from [0 0]) (to [(cosd theta) 0]) (stroke red) (stroke-width 4))
  (line sin (from [(cosd theta) 0]) (to (polar 1 theta)) (stroke green) (stroke-width 4))
  (circle p (r 0.07) (pos (polar 1 theta)) (fill ink))
  (text_ $'cos θ = {(cosd theta):+.2f}' (pos [-1.3 -1.5]) (fill red) (font number))
  (text_ $'sin θ = {(sind theta):+.2f}' (pos [0.15 -1.5]) (fill green) (font number)))
(canvas v (x -1.4) (y -1.65) (width 2.8) (height 3.05) s
  (on-drag p (move theta (to (. (or? (to-polar pointer) [1 theta]) 1)))))
(slider turn (move theta (from 0) (to 360)) (label 'θ'))
The figure that it draws. Drag the point, or turn the slider.

One figure in three steps

A figure is its variables and the shapes that depend on them. Add a control and readers can change a variable, and everything that reads it follows.

1A still figure

An angle, a circle, and the two lines that it sets.

(real theta 40 (wrap 0 360))
(scene s
  (circle rim (r 1) …)
  (line cos … (to [(cosd theta) 0]))
  (line sin … (to (polar 1 theta)))
  (circle p … (pos (polar 1 theta))))
(canvas v … s)

2Add a slider

One line. The slider moves theta, and the lines follow.

(real theta 40 (wrap 0 360))
(scene s …)
(canvas v … s)
(slider turn (move theta (from 0) (to 360)))

3Make the point draggable

One more line. Dragging the point moves theta too.

(real theta 40 (wrap 0 360))
(scene s …)
(canvas v … s
  (on-drag p (move theta (to …))))
(slider turn (move theta (from 0) (to 360)))

The compiler checks every figure

The compiler works out the range of every value. When a value could leave the range that a shape needs, the figure does not compile, and the error gives the line, the column and a way to fix it.

circle.mtp
(real k 1 (>= 0) (<= 3))
(slider size (move k (from 0) (to 3)))
(scene s (circle c (r (- k 2))))
mtp check circle.mtp
circle.mtp:3:23: c's r may break (>= 0): constrain what it reads so this can be proved, or declare c as circle|none

A figure that could draw something undefined, such as a circle with a negative radius, never reaches a reader.

Every figure gets the same care

These come with the runtime, so no figure has to build them again.

  • KeyboardSliders, buttons and players work from the keyboard.
  • Screen readersEach control and each canvas carries a label written in the source.
  • TouchEvery drag also works by tapping.
  • Light and darkEach color has a dark value, and the page picks.
  • Reduced motionAnimations respect the reader's setting.
  • Saved as dataA figure is a .mtpc file, so it keeps working when the runtime improves.
