# mathterpiece docs

mathterpiece (mtp) is a small language for math figures that readers can drag, slide and play.
You write a figure in a `.mtp` file, the compiler checks it and writes a `.mtpc` file, and a
JavaScript runtime draws it on any web page.

Start with the quickstart, which takes you from nothing to a live figure on a page. The exact
rules of the language are in the [specification](https://spec.mtp-lang.org).
